# ZeroChess

A lightweight, fully client-side chess website. Play against the computer or
against a friend on the same device

Built with plain HTML, CSS, and JavaScript. No frameworks, no build tools, no
dependencies. Open `index.html` and it runs.

---

## Features

### Game Modes
- **vs Computer** — play against a built-in engine
- **Two Players** — local pass-and-play on a single device

### Difficulty Levels
- Easy
- Medium
- Hard
- Expert

### Side Selection
- White
- Black
- Random

### Time Controls
- Unlimited
- 10 minutes
- 5 minutes
- 3 minutes

### Board
- Standard 8×8 board with piece placement
- Coordinates on all four sides
- Flip board button
- Five board themes: Red & Black (default), Crimson, Ember, Steel, Carbon, Blood

### Interface
- Move history panel
- Game info panel with live evaluation bar, status, and material count
- Player clocks for both sides
- Captured pieces display
- Settings model (theme, coordinates, highlights, sound, animations)
- How to Play modal with piece movement reference
- Promotion picker modal
- Game over modal with rematch option
- Full keyboard support (Esc to close modals)

### Controls
- New Game
- Undo
- Flip Board
- Hint
- Resign

### Visuals
- Red and black theme
- Animated background with cool visuals
- slide-in animations on the menu
- Custom SVG icons throughout — no icon fonts, no emoji, no image files
- Fully responsive from desktop down to phone


## Tech

- **HTML5** — semantic markup, inline SVG sprite for icons
- **CSS3** — custom properties, grid, flexbox, keyframe animations
- **Fonts**
  - Korataki ExtraBold (800) — titles, headings, logo
  - Korataki Bold (700) — subtitles, tags
  - Inter — body text and small labels

No JavaScript frameworks. No CSS frameworks. 

## Getting Started

1. Clone the repository
2. Open `index.html` in any modern browser
